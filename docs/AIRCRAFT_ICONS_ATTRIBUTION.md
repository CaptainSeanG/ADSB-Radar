# Aircraft Icon Attribution

ADSB Radar bundles five silhouettes from the supplied `ADS-B_Radar_Free_Aircraft_SVG_Icons` pack:

- `single-prop.svg`: source `cessna.svg`
- `multi-prop.svg`: source `dh8a.svg`
- `small-jet.svg`: source `learjet.svg`
- `large-jet.svg`: source `b737.svg`
- `helicopter.svg`: source `a7.svg`

The supplied `Readme and Attribution.rtf` grants personal and commercial use and requires a backlink. The radar includes the attribution link in this document and the project website:

Icons by ADS-B Radar for macOS: https://adsb-radar.com

All bundled silhouettes use a viewBox with the aircraft nose oriented toward the top of the image. The canvas renderer applies the target's screen-relative track rotation exactly once.
